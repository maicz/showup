## Known environment note

On the baseline machine, Docker Desktop reports an arm64 server while `postgis/postgis:18-3.6` reports amd64. Testcontainers warns that emulation can make the suite slower. This warning does not justify excluding integration tests; measure it in each candidate if it affects a performance budget.
